RECIPE POCKET — COMPACT CARD EDITION (v2)

Upload ALL files from this ZIP directly to the ROOT of your GitHub repository (not a nested folder).

GitHub Pages:
1. Create a GitHub repository named recipe-pocket. Make it Public for easy free Pages hosting.
2. Upload index.html, icon.svg, manifest.webmanifest, sw.js, and .nojekyll to the repository root.
3. Open repository Settings > Pages. Select Deploy from a branch, main, /(root), then Save.
4. After Pages finishes publishing, visit https://YOUR-USERNAME.github.io/recipe-pocket/ in Safari on iPhone.
5. In Safari choose Share > Add to Home Screen, and enable Open as Web App if prompted.
6. Launch using the Home Screen icon while connected once, then test offline in Airplane Mode.

IMPORTANT:
- Recipes and photos are private, stored in each device's local browser/app storage (IndexedDB), not in GitHub.
- Export a JSON backup often using the gear icon, save in iCloud Drive or Files.
- Clearing site data, deleting the installed app, or device loss may erase recipes.
- Not yet included: import from any recipe URL, iOS Share Sheet extension, automatic device sync, automatic scaling.
- The HTML/CSS/JavaScript are public in a public GitHub repository. Do not put private recipes in repository files.
